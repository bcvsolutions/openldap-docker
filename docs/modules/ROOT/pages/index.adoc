This is a OpenLDAP container originally cloned from Osixia enhanced with:

* Optional backup encryption.
* Disabled scheduled backups.
* Removed AWS S3 bucket upload mechanism.
* Added LDAP schema versioning.

This container is further incorporated into `iam-app-directory-server` RPM package for the IAM appliance.
